¿Cómo funciona AzCode?

Escribes instrucciones en un archivo .az. Un programa Python las lee y hace lo que le pides.

No necesitas saber de compiladores para empezar. Seguiremos una suma desde el texto hasta el resultado.

Las palabras del lenguaje están en portugués brasileño. Las explicaciones están en español.

Una instrucción pide una acción.

Este programa muestra un saludo en la consola.

Un ejemplo completo
programa Saludo;

    escrever("Hola");
fim

  • fim lo cierra.

El léxico reconoce las piezas.

A estas piezas también se les llama tokens.

AzCode
numero suma = a + b;
numerosuma=a+b;
Reconoce números, nombres y signos. Ignora espacios y comentarios que empiezan con #.

El sintáctico comprueba la forma.

AzCode
numero suma = a + b;
  1. Ve una declaración numero.
  2. Lee el nombre suma.
  3. Exige =.
  4. Recoge la expresión a + b.
  5. Exige ;.
Si falta un símbolo o aparece una instrucción desconocida, el programa se detiene.

Una instrucción se guarda como datos.

La lista de instrucciones contiene cuatro datos por instrucción.

Representación actual en Python
("numero", "suma", [], "a + b")
  1. Operación: numero.
  2. Nombre: suma.
  3. Parámetros: vacíos, porque no es una función.
  4. Expresión: a + b, todavía sin calcular.

Las variables guardan resultados.

Explora la expresión
De AzCode a una función de Python
raiz(25) calcula 25 ** 0.5.
Fragmentos de scr/interprete.py
def raiz(numero):
    if numero < 0:
        raise ValueError("Número negativo")
    return numero ** 0.5
  1. ast.parse crea un nodo Call llamado raiz.
  2. resolver lee su argumento 25.
  3. Reconoce el nombre y llama a nuestra función raiz, que usa numero ** 0.5.
  4. Recibe 5.0 y lo usa como resultado.
En numero resultado = raiz(25);, ejecutar guarda ese 5.0 en resultado. Una raíz negativa produce un error básico.
Dos formas, una misma operación
Una potencia puede ser Call o BinOp.
Dos expresiones de AzCode

Call: potencia(...) busca el nombre y llama a operadores.pow.
BinOp: ** se reconoce como ast.Pow y el diccionario operaciones selecciona operadores.pow.

if nombre == "potencia":
    return operadores.pow(*argumentos)

ast.Pow: operadores.pow

El AST aparece al evaluar una expresión.
  1. El léxico reconoce las piezas.
  2. El sintáctico prepara una expresión de texto.
  3. evaluar llama a ast.parse.
  4. resolver recorre ese árbol.
Los árboles organizan operaciones, comparaciones, llamadas y valores. No dibujan todo el archivo .az como un único árbol.
Entrada al cálculo en evaluar
return resolver(
    ast.parse(expresion, mode="eval").body
)

Añadir una capacidad requiere conectarla al léxico, al sintáctico y al intérprete.
Repetir mientras se cumpla una condición.
AzCode
numero contador = 1;
enquanto (contador <= 5) {
    escrever(contador);
    contador = contador + 1;
}
El sintáctico guarda el cuerpo del bloque. El intérprete vuelve a comprobar la condición y llama a procesar para cada repetición.
Un contador que avanza solo.
AzCode
para contador de 1 ate 5 {
    escrever(contador);
}
Ambos límites son inclusivos. El intérprete usa range(desde, hasta + 1). Si el inicio es mayor que el final, no hay repeticiones.
Elegir una opción sin ejecutar las otras.
AzCode
escolha (opcion) {
    caso 1:
        escrever("Hola");
    caso 2:
        escrever(raiz(25));
    padrao:
        escrever("Otra opción");
}
El selector se calcula una vez. Ejecuta el primer caso que coincide; padrao solo se usa si no hay coincidencias.
