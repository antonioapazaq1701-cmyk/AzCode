Los siguientes ejemplos van entre inicio y fim.
Cada instrucción termina con ;

1. GUARDAR DATOS
numero edad = 20;
texto nombre = "Antonio";
booleano estudiante = verdadeiro;
booleano terminado = falso;

2. MOSTRAR EN CONSOLA
escrever("Hola");
escrever("Edad: " + edad);
escrever(estudiante);
Los booleanos se muestran como verdadeiro o falso.

3. ESCRIBIR UNA RESPUESTA EN LA CONSOLA
texto ciudad = ler("Tu ciudad: ");
numero cantidad = ler("Cantidad: ");
booleano activo = ler("Activo: verdadeiro o falso: ");
ler recibe lo que escribes y pulsas con Enter.
numero convierte la respuesta a número. Usa punto para decimales.
booleano acepta verdadeiro o falso.

También puedes declarar primero y leer después:
numero valor;
ler(valor);
escrever(raiz(valor));

numero comienza en 0, texto en "" y booleano en falso.
ler(valor) pide un dato y lo guarda en una variable ya declarada.
Convierte la entrada según su tipo. Un número debe ser válido y
un booleano debe escribirse como verdadeiro o falso.

4. HACER CUENTAS
escrever(8 + 2);           # suma: 10
escrever(8 - 2);           # resta: 6
escrever(8 * 2);           # multiplicación: 16
escrever(8 / 2);           # división: 4.0
escrever(10 % 3);          # resto: 1
escrever(2 ** 3);          # potencia: 8
escrever(potencia(2, 3));  # también potencia: 8
escrever(raiz(25));        # raíz cuadrada: 5.0
escrever((2 + 3) * 4);     # paréntesis: 20
escrever(-5 + 2);          # negativo: -3
raiz trabaja con números mayores o iguales a cero.

¿CÓMO LO HACE POR DENTRO?
raiz(25): el intérprete reconoce una llamada y usa 25 ** 0.5 sin importar math.
potencia(2, 3): reconoce una llamada y usa operator.pow(2, 3).
2 ** 3: reconoce una operación ast.Pow y usa la misma función pow.
ler("Edad: "): reconoce una llamada y usa input para esperar tu respuesta.
ler devuelve texto. Al declararlo como numero se convierte con float.
Por ejemplo, la respuesta "20" se guarda como 20.0.

La biblioteca ast organiza cada expresión en un árbol.
No hace la cuenta sola: resolver recorre sus partes y calcula.
En 2 + 3 * 4 resuelve primero 3 * 4 y luego suma 2: resultado 14.
En raiz(25) el nodo padre es una llamada; su hijo es el número 25.
En 2 ** 3 el nodo padre es una operación; sus hijos son 2 y 3.

5. COMPARAR Y USAR BOOLEANOS
booleano mayor = edad >= 18;
escrever(edad == 20);       # igual
escrever(edad != 20);       # diferente
escrever(edad < 30);        # menor
escrever(edad > 10);        # mayor
escrever(edad <= 20);       # menor o igual
escrever(edad >= 20);       # mayor o igual
escrever(mayor e estudiante);  # ambos verdaderos
escrever(mayor ou estudiante); # al menos uno verdadero
escrever(nao estudiante);      # invertir el booleano

6. CREAR FUNCIONES SENCILLAS
funcao doble(valor) = valor * 2;
funcao sumar(primero, segundo) = primero + segundo;
escrever(doble(5));       # 10
escrever(sumar(3, 4));    # 7
numero resultado = doble(8);

Una función tiene un nombre, parámetros entre paréntesis y una
expresión después del igual. Esa expresión es el resultado.
Declárala antes de llamarla. Puede usar funciones declaradas y
variables disponibles. Sus parámetros no cambian las variables
del programa. No tiene bloques ni una instrucción de retorno.

NUEVO: REPETIR Y ESCOGER
Los ejemplos siguientes van entre inicio y fim.
Las instrucciones llevan ;. Los bloques abren con { y cierran con }.

WHILE EN PORTUGUÉS: enquanto
numero contador = 1;
enquanto (contador <= 5) {
    escrever(contador);
    contador = contador + 1;
}
Muestra 1, 2, 3, 4 y 5. El contador debe cambiar para que termine.
Si un ciclo no termina, Ctrl+C detiene el programa.

FOR EN PORTUGUÉS: para
para contador de 1 ate 5 {
    escrever(contador);
}
Incluye los límites 1 y 5. El contador avanza de uno en uno.
Los límites deben ser enteros. De 5 a 1 no ejecuta ninguna vuelta.
El contador se crea automáticamente y queda con su último valor.

CAMBIAR UNA VARIABLE
numero total = 0;
total = total + 5;
La variable debe estar declarada y conserva su tipo.
Declara las variables antes del ciclo; dentro cambia su valor.
No vuelvas a declarar el mismo nombre en cada repetición.

ESCOGER UNA OPCIÓN: escolha
numero opcion = ler("Opción: ");
escolha (opcion) {
    caso 1:
        escrever("Hola");
    caso 2:
        escrever(raiz(25));
    padrao:
        escrever("Otra opción");
}
Se ejecuta solo el primer caso que coincide. No necesita break.
padrao es opcional y se usa si no coincide ninguno.
Los casos pueden comparar números, texto o booleanos.
Se pueden colocar ciclos y elecciones dentro de otros bloques.
Es una selección de valores; no implementa patrones avanzados de Python.
