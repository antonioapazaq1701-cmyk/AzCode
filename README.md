# AzCode

Intérprete educativo desarrollado en Python, con 22 programas de ejemplo y documentación en español.

## Ejecutar

Requiere Python 3.

```powershell
python -B src/main.py programas/01HolaMundo.az
```

Los ejemplos están en `programas`, las instrucciones en `instrucciones` y las guías visuales en `Ayuda`.
